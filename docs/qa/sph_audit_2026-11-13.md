# SPH equivalence audit (2026-11-13)

Scope: `garnet/sph.py`, its callers (`examples/`, `tests/`), `garnet/griffin_xs.py`, and the way `garnet/solver.py`, `garnet/tri.py`, `garnet/power.py` and `garnet/transient.py` consume SPH-corrected materials. No code was modified. Evidence scripts and outputs are in [sph_audit_evidence/](sph_audit_evidence/).

Every statement carries one of four tags: **[code]** read in the repository, **[source]** read in a document I opened (full text unless stated), **[measured]** produced by a script in the evidence folder, **[inferred]** my reasoning. Three literature surveys written for this audit are kept with the evidence: `lit_formulation.md`, `lit_assembly_level.md`, `lit_benchmarks.md`; they tag every claim verified / not verified and list what could not be opened.

Notation: `i` equivalence region, `g` group, `φ` reference (transport) flux, `Φ` flux of the corrected coarse diffusion solve, `μ_{i,g}` SPH factor, `V_i` region volume, overbar = region average.

## 1. What GARNET does

### 1.1 Flux–volume homogenization, `flux_weighted_homogenize` ([sph.py:103–224](../../garnet/sph.py#L103-L224)) [code]

Input: reference flux `φ_{g,c}` on fine cells `c`, fine materials, `region_map` `i(c)`, cell volumes `V_c`. Cells blended between two materials (`mix_material`, `mix_weight`) are split into two fractional entries carrying the same cell flux ([sph.py:69–100](../../garnet/sph.py#L69-L100)).

```
φ̄_{i,g}      = Σ_{c∈i} φ_{g,c} V_c / V_i,   V_i = Σ_{c∈i} V_c                              (sph.py:177-179)
Σ_{x,i,g}    = Σ_{c∈i} Σ_{x,c,g} φ_{g,c} V_c / Σ_{c∈i} φ_{g,c} V_c,   x ∈ {a, νf, κf, t}    (sph.py:187-197)
D_{i,g}      = 1 / (3 Σ_{tr,i,g}),  Σ_{tr,i,g} = flux-volume average of 1/(3 D_{c,g})       (sph.py:198-200)
Σ_{s,i,g→g'} = Σ_{c∈i} Σ_{s,c,g→g'} φ_{g,c} V_c / Σ_{c∈i} φ_{g,c} V_c   (source-group weight) (sph.py:202-208)
χ_{i,g}      = fission-production-weighted average of χ_{c,g}                               (sph.py:209-217)
```

Groups with zero flux weight fall back to volume weighting ([sph.py:185–190](../../garnet/sph.py#L185-L190)). Reaction-rate preservation `Σ_{x,i,g} φ̄_{i,g} V_i = Σ_{c∈i} Σ_{x,c,g} φ_{g,c} V_c` holds by construction and is tested ([test_sph.py:89–114](../../tests/verification/test_sph.py#L89-L114)).

### 1.2 Corrected material, `_scale_material` ([sph.py:425–461](../../garnet/sph.py#L425-L461)) [code]

```
Σ̃_{a,i,g} = μ_{i,g} Σ_{a,i,g},  ν̃Σ_f = μ νΣ_f,  κ̃Σ_f = μ κΣ_f,  Σ̃_t = μ Σ_t
Σ̃_{s,i,g→g'} = μ_{i,g} Σ_{s,i,g→g'}      (matrix row g, i.e. the SOURCE group)              (sph.py:457)
χ̃ = χ                                                                                       (sph.py:458)
D̃_{i,g} = D_{i,g} / μ_{i,g}   if D_SCALING == "inverse"   (module default, sph.py:422)      (sph.py:452-454)
D̃_{i,g} = μ_{i,g} D_{i,g}     if D_SCALING == "direct"
```

A second, independent implementation, `volume_homogenize(sph_factors=...)` ([griffin_xs.py:255–268](../../garnet/griffin_xs.py#L255-L268)), multiplies `Σ_t, Σ_a, νΣ_f, Σ_s` rows and `κΣ_f` by `μ` and then sets `D = 1/(3 Σ_t μ)`, i.e. hard-codes `D/μ` whatever `D_SCALING` says.

How the diffusion solver consumes the corrected material [code]: `Fields` ([solver.py:165–198](../../garnet/solver.py#L165-L198)) builds per-cell `removal = Σ_a + Σ_{g'≠g} Σ_{s,g→g'}` ([materials.py:107–110](../../garnet/materials.py#L107-L110)), which scales as `μ_g Σ_{r,g}` (consistent); in-scatter `g'→g` is read from `sigma_s[g'][g]` and therefore carries `μ_{g'}` (consistent with the source-group convention); the fission source is `χ_g Σ_{g'} νΣ̃_{f,g'} Φ_{g'}` (carries `μ_{g'}`, `χ` untouched); face diffusion coefficients are harmonic means of the two cell values ([stencil.py:108–116](../../garnet/stencil.py#L108-L116), [tri.py:128](../../garnet/tri.py#L128)); `sigma_t` is used only by the SP3/SPN operators ([solver.py:1044](../../garnet/solver.py#L1044), [solver.py:1259](../../garnet/solver.py#L1259)). There is no double application: the corrected `Material` is an ordinary material and nothing downstream re-applies `μ`. Mixed cells apply the corrected partner material with the same volume fraction used in the homogenization, so the blend is consistent.

### 1.3 Factor solve, `sph_correct` ([sph.py:525–752](../../garnet/sph.py#L525-L752)) [code]

Unknowns `x_{i,g} = ln μ_{i,g}` on the live set `L = {(i,g): φ̄^ref_{i,g} > 10⁻¹² max φ̄^ref}` ([sph.py:626](../../garnet/sph.py#L626)); frozen entries keep `μ = 1`. The coarse solve is a black-box callable returning `Φ_{i,g}(μ)` from a **k-eigenvalue** diffusion solve with the corrected materials, plus its `k`. All callers use `region_average(res.flux_numpy, region)` on the **same mesh** as the reference.

Residual (Anderson path [sph.py:727–736](../../garnet/sph.py#L727-L736); the Newton paths use `_sph_residual`, [sph.py:484–522](../../garnet/sph.py#L484-L522)):

```
f_{i,g}(x) = ln( φ̄^ref_{i,g} / N^ref ) − ln( Φ_{i,g}(μ) / N^Φ(μ) ) − x_{i,g}
N^ref = Σ_{(j,h)∈L} w_{j,h} φ̄^ref_{j,h},     N^Φ = Σ_{(j,h)∈L} w_{j,h} Φ_{j,h}(μ)
```

with `w = 1` by default ("sum", [sph.py:636](../../garnet/sph.py#L636)), `w = νΣ_{f,j,h} V_j` for `norm_weight=production_weight(...)` ([sph.py:227–247](../../garnet/sph.py#L227-L247)), or no per-iteration normalization for `norm_weight="none"`, where the reference is rescaled once by `const = Σ_L Φ⁰ / Σ_L φ̄^ref` from the uncorrected coarse solve ([sph.py:649–652](../../garnet/sph.py#L649-L652)). **The sums run jointly over regions and groups: one constant for the whole problem, not one per group.** Root: `μ_{i,g} Φ_{i,g} / N^Φ = φ̄^ref_{i,g} / N^ref`.

Iteration: Anderson mixing (depth 5) of the fixed point `x ← x + f` (Walker–Ni, [linalg.py:1341–1366](../../garnet/linalg.py#L1341-L1366)); convergence `max |e^{f} − 1| < tol` ([sph.py:736–737](../../garnet/sph.py#L736-L737)); after `max_iter` the last solved iterate is returned with `converged=False` ([sph.py:746–752](../../garnet/sph.py#L746-L752)). `method="hybr"/"lm"` use SciPy's dense trust-region root finder with `xtol = tol·10⁻⁴` ([sph.py:667–690](../../garnet/sph.py#L667-L690)); `method="jfnk"` uses SciPy Krylov with `fatol = tol` ([sph.py:692–716](../../garnet/sph.py#L692-L716)); for these `converged` is SciPy's success flag. A non-positive coarse region flux returns a pull-back residual `10·x` ([sph.py:506–513](../../garnet/sph.py#L506-L513)).

### 1.4 Reported eigenvalue and flux [code]

`SphResult.k_eff` is the eigenvalue of the coarse solve with the final corrected materials ([sph.py:688](../../garnet/sph.py#L688), [714](../../garnet/sph.py#L714), [751](../../garnet/sph.py#L751)). The power iteration normalizes its eigenvector to `Σ_cells νΣ̃_f·Φ = n_cells` ([solver.py:854](../../garnet/solver.py#L854), [911](../../garnet/solver.py#L911)); this constant cancels in the residual through `N^Φ`.

### 1.5 Conversion back to a reference-equivalent flux [code]

There is none, and none is needed for reaction rates: a model built with `core.with_materials(sph.corrected_materials)` ([model.py:1402–1419](../../garnet/model.py#L1402-L1419)) reports power as `Σ_g κ̃Σ_{f,g} Φ_g = Σ_g μ_g κΣ_{f,g} Φ_g` ([power.py:130](../../garnet/power.py#L130)), which is the reference-equivalent rate `κΣ_f φ`. The physical flux `φ = μΦ` is never formed. Everything that reads `result.flux` directly sees `Φ`: flux peaking in `summary()`, the coarse flux sampled by pin-power reconstruction ([pin_power.py:125](../../garnet/pin_power.py#L125)), the `1/(v_g Δt)` term added to removal in transients ([transient.py:508–524](../../garnet/transient.py#L508-L524)) with velocities that carry no `μ`, and the Doppler update of `D` from `1/D + 3 ΔΣ_a` ([feedback.py:255–263](../../garnet/feedback.py#L255-L263)).

### 1.6 What the examples and tests exercise [code]

Every SPH example and test uses `region = material_map` (one factor per material type: all 30 HP-MR fuel hexes share one factor) and runs the coarse solve on the **same mesh** as the transport reference ([examples/hpmr_sph_sn_reference.py:83–93](../../examples/hpmr_sph_sn_reference.py#L83-L93), [tests/validation/test_hpmr_sph.py:35–41](../../tests/validation/test_hpmr_sph.py#L35-L41)). The HP-MR constants are already assembly-homogenized, so these runs fold the SP3/S_N-versus-diffusion angular difference into material-wise factors. No example or test generates per-assembly factors in a colorset or core and applies them on a coarser node mesh, which is the workflow described in the task. `sph_get_correct`, `sph_df_correct` (shelved) and `sph_correct_monolithic` have no callers outside `sph.py` [code]; only `sph_correct` is exercised.

## 2. Reference formulation

Primary sources opened in full: Labouré et al. 2019 (accepted manuscript, OSTI 1498269, "L19"); DRAGON5 user guide IGE-335 §3.11 (merlin.polymtl.ca, "IGE335"); Hébert 2015 7ICMSNSE reformulation paper ("H15"); DONJON5 guide IGE-344 §7.3.2; INL/EXT-16-39120 (MAMMOTH SPH, "O16"); INL/EXT-17-41516 (HTR SPH, "S17"); ANL/NSE-20/23 (Empire, "EMP"); Pandya et al. 2022 (OSTI 1870247); Takasugi et al. 2023 (INL preprint); VTB pages from the GitHub source. Abstract only: Ortensi et al. 2018 PJFNK-SPH ("O18", no accepted manuscript on OSTI), Hébert 1993 NSE 113/115, Hébert & Benoist 1991. Not accessible: Kavenoky 1978 (IAEA-TECDOC-231), Hébert's textbook §4.4, Hébert CEA-N-2209 (1981), Laurier 2016 thesis, Serpent wiki, Griffin online documentation. Full references and URLs are in `lit_formulation.md`.

### 2.1 Defining condition and corrected quantities [source]

- L19 Eq. (4)–(6): `Σ_{m,g} = μ_{m,g} Σ^ref_{m,g}` for the removal, fission and scattering cross sections, chosen so that `Σ_{m,g} φ_{m,g} = Σ^ref_{m,g} φ^ref_{m,g}`; hence `μ_{m,g} ≡ φ^ref_{m,g}/φ_{m,g}`. `χ` is not corrected ("the SPH correction will only apply to the cross-sections and diffusion coefficient").
- IGE335 Eq. (3.42)–(3.43) (diffusion macro-calculation): `∇·J_g + μ_g Σ_g (φ_g/μ_g) = (χ_g/k) Σ_h μ_h νΣ_{f,h} (φ_h/μ_h) + Σ_h μ_h Σ_{s0,g←h} (φ_h/μ_h)`, `J_g = −μ_g D_g ∇(φ_g/μ_g)`; "Diffusion coefficients and all P0 cross sections (including the total cross section NTOT0) must be multiplied by μ_g. Scattering matrix terms Σ_{s0,g←h} must be multiplied by μ_h. Fluxes must be divided by μ_g." H15 §1: "all cross sections and diffusion coefficients are multiplied by the equivalence factors. In order to preserve the reference reaction rates, the corresponding fluxes are divided by the same factors."
- Consequences: the scattering transfer out of group `h` carries the factor of the *source* group `h`; the macro flux is `Φ = φ^ref/μ`, the reference-equivalent flux is `φ^ref = μ Φ`; reaction rates computed with corrected cross sections and `Φ` need no further factor.

### 2.2 Diffusion coefficient [source]

Every opened source that states a rule multiplies `D` by `μ`: IGE335 Eq. (3.43); H15 §2; L19 Eq. (7) "In practice, the diffusion coefficients are also corrected to better match the reference currents, as discussed in [6]: D_{m,g} = μ_{m,g} D^ref_{m,g}" and Eq. (14); O16 Eq. (5) `∇·μD∇φ`; Zhang et al. 2025 (PARCS) `D·μ`. No source divides `D` by `μ` or leaves it uncorrected in a diffusion macro-calculation. IGE335 Eq. (3.44)–(3.46) gives the transport-side statement for SPN macro-calculations: even-parity total cross section **multiplied** by `μ_g`, odd-parity total cross section (the one that defines `D = 1/3Σ_1`) **divided** by `μ_g`, odd-parity fluxes unchanged. The reason [inferred, consistent with every source]: with `φ = μΦ` and `μ` constant inside a region, Fick's law `J = −D∇φ = −(μD)∇Φ` gives `D̃ = μD`; this preserves the current inside each region and makes a common rescaling of all `μ_g` of one group an exact symmetry of the corrected operator.

### 2.3 Normalization [source]

- Why: with reflective boundaries, if `(Φ, μ)` solves the corrected problem then `(c_g Φ_g, μ_{m,g}/c_g)` does too for any per-group constants `c_g`, so `G` extra constraints are needed (L19 §3.1, citing Hébert 1981; IGE344 §7.3.2). L19: "if only one or no constraint is imposed (e.g. the normalization factor is a constant independent of the energy group), convergence is never reached."
- Flux–volume ("average flux") normalization, per group: `Σ_m V_m Φ_{m,g} = Σ_m V_m φ^ref_{m,g}` (IGE335 keyword `STD`, the default: "In each macro-group ... the averaged SPH factor is equal to one"; L19 Eq. (12)–(13); O16; Rachamin & Kliem 2017 Eq. (2)). L19 Eq. (15)–(22): the normalization is applied to every term except the fission term; the converged factors are then independent of the eigenvalue used in the fission term.
- Selengut normalization (IGE335 `SELE ALB/FD/MWG/EDF`; Hébert & Mathonnière 1993): the macro flux level is set so that the macro flux at the assembly surface equals the reference surface flux; for a fully homogenized assembly this yields `μ = 1/ADF` (IGE335 `HOMO`: "The SELE option allows an SPH factor equal to the inverse of the discontinuity factor to be calculated"). Other options: `ASYM` (pin one mixture to `μ = 1`), `STD FISS` (flux–volume over fissile zones only, "useful for representing assemblies containing reflector zones").
- Vacuum boundaries: the boundary term breaks the symmetry, so no normalization should be used; L19 §3.2 "when normalization factors were introduced in [2], it was only designed to address the singularity of the system with reflecting boundaries and in no way intended to be used in other cases", and with the fission term scaled by the reference `k_eff` the reaction rates, the total vacuum leakage and the eigenvalue are reproduced (Eq. 24–27). IGE335: "If boundary leakage is present, no normalization condition is used but the SPH iterations are difficult to converge in this case." L19 Table 1 (3×3 supercell, 4 groups, Serpent reference): no equivalence +1312 pcm; SPH with normalization +414 pcm; SPH without normalization 0.0 pcm; SPH-DF +0.2 pcm. HTTR (Table 4): 1865 pcm uncorrected, 1526 pcm with normalization, 0 pcm without. L19's remedy when leakage is small: keep the normalization but add discontinuity factors on the vacuum boundary (hybrid SPH-DF), which is stable as the vacuum boundary vanishes.
- In Griffin practice (EMP §6.1, Takasugi 2023): fixed reference `k_eff`, no normalization with vacuum boundaries; SPH regions may be restricted to the fuel (plus near reflector) while still reproducing `k_eff` and power (L19 §3.3).

### 2.4 Iteration and convergence [source]

Classical fixed point `μ^{n+1} = φ^ref/Φ(μ^n)` with normalization, convergence on `max |μ^{n+1}/μ^n − 1|` (Rachamin & Kliem 10⁻⁵; IGE335 default 10⁻⁴, 200 iterations, abort after 10 iterations of growing error; `BELL` and Anderson acceleration exist). Known failures: reflectors, more than two groups, vacuum boundaries (O16 §3.2 citing Ragusa et al. 2007, Hébert 1981, Pautz 2006); negative or noisy (Monte Carlo) reference fluxes in reflectors (L19 §3.3, §5.3; Takasugi 2023; HTR-10 report). INL's fix: Newton (PJFNK) on the fixed-k source-free problem with the factors updated at every residual evaluation, 5× (diffusion) to 10–15× (transport) faster than Picard, converging reflector and vacuum cases Picard could not (O18 abstract; O16 §5.1 Table 2).

### 2.5 Convention check across codes [source]

DRAGON5/DONJON5, Griffin/MAMMOTH, INSTANT, DYN3D (HZDR, KIT), PARCS (KIT), nTRACER/SPHINCS, the PSI CASMO→DYN3D workflow: all define `μ = φ^het/φ^hom` and multiply the homogenized cross sections (and `D` where stated) by `μ`. No opened code defines the inverse ratio with division. Serpent's own options and the APOLLO/CASMO internals could not be verified.

### 2.6 Assembly level [source unless marked]

- A single fully homogenized assembly with reflective boundaries and flux–volume normalization gives `μ = 1` (IGE335 `HOMO`: the factors "are all set equal to 1.0 (no correction)" unless Selengut normalization is used). Non-trivial factors need either a Selengut normalization (then `μ = 1/ADF`) or a heterogeneous environment.
- Factors generated in reflective supercells and transported to a vacuum-bounded core failed on a prismatic HTR (S17 Tables 13–14: 2000–2500 pcm bias reduced by ~250 pcm, worse when regions were restricted); the authors attribute it to SPH's "weak relation preserving interface currents, unlike the Generalized Equivalence Theory".
- INL's current practice is "non-fundamental mode" SPH: reference fluxes tallied in the **full 3-D core**, in a Serpent model subdivided to match the Griffin mesh, factors solved on the same geometry at each state point, applied to at least all fuel regions (Takasugi 2023 §1–2; INL/EXT-20-59992 §2.2; Griffin training INL/MIS-23-71297).
- Reflector and non-fuel regions: restrict the SPH set when their reference flux is small, noisy or negative (L19 §3.3; HTTR excluded the permanent reflector and the top/bottom slices; HTR-10 cut the boronated bricks out and imposed vacuum; IPEN/MB-01 corrected the core only or core plus part of the reflector). Control rods and drums were kept in the SPH set where their worth mattered (HTTR control-rod columns; VTR control assemblies at inserted/withdrawn state points; INL drum study: fuel plus first reflector ring, drum itself not corrected).
- SPH vs ADF at assembly level: SPH preserves region reaction rates, not interface currents; with Selengut normalization it is equivalent to an ADF for a homogenized assembly; L19's hybrid adds DFs where currents must be preserved. Evidence that SPH alone is adequate at assembly level **when the factors come from the full-core reference**: VTR (hex SFR, assembly × 5 axial layers, 6 groups): 0 pcm at 18 state points with rods in and out, flux RMSE 0.05–0.18 %, rod worth preserved; HTTR: 0 pcm, power RMS 0.08 %; HTR-10: within ~120 pcm.
- Microreactors: the Empire work (ANL/NSE-20/23; Pandya 2022) is **pin-cell-level** SPH (fuel pins only, 2-D core, 15 groups, tabulated drum states): k reproduced exactly, pin power RMS 0.55–0.61 %, but SPH could not be converged when moderator and heat-pipe cells were included. For the HP-MR itself ANL used Griffin diffusion+SPH only on the 3-D unit cell (ANL/NEAMS-21/3, 208 material-block zones); the full-core production models use heterogeneous DFEM-S_N without SPH (Stauff et al. NSE 2024; ANL/NEAMS-24/3; VTB MRAD), and Stauff et al. state that diffusion+SPH on a homogeneous core "shows promise ... However, thorough verification against high-fidelity multiphysics simulations, is necessary". So the belief that the Empire work shows SPH alone is adequate for the HP-MR at assembly level is only partly supported [inferred from the sources above]: it is demonstrated at pin and material-block level, and at assembly level on the VTR, not on an HP-MR core.
- **Update 2026-11-13 (Kumar et al. 2026, provided by the author):** Griffin now demonstrates assembly-level SPH on the 2-D SIMBA core, which is Empire-like (18 hex fuel assemblies, UN fuel, YH moderator, Na heat pipes, Be reflector, 12 B4C drums), with one equivalence zone per fuel hex, SPH in the fuel only, factors from a full-core Serpent reference with vacuum boundary, and full-core per-group form functions for pin powers: core pin-power RMS 0.6 %, max 2.3 % at the tabulated states [source]. This is assembly-level evidence for a heat-pipe microreactor of the Empire family; it is still 2-D, not the HP-MR, and errors grow at drum angles between tabulation points (§9.3).

## 4. Multiply or divide, in GARNET's convention

GARNET defines `μ_{i,g} = φ̄^ref_{i,g} / Φ_{i,g}` with normalized fluxes (reference over coarse), as every code surveyed does. With that definition:

1. Cross sections are **multiplied** by `μ`: `Σ_a, νΣ_f, κΣ_f, Σ_t` and every scattering transfer **out of** group `g` (row `g` of `sigma_s`). GARNET does this correctly. `χ` is untouched.
2. The diffusion coefficient is **multiplied** by `μ` as well: `D̃ = μD`. GARNET's default **divides** it; that is the bug (F1), not a convention. The "transport-consistent" argument for dividing is wrong because the transport cross section that defines `D` lives in the odd-parity equation, where the SPH rule divides `Σ_t` by `μ` (IGE335 Eq. 3.46), which is `D̃ = μD` again.
3. The coarse flux of the corrected solve is the reference flux **divided** by `μ`: `Φ = φ^ref/μ`. To report a reference-equivalent (physical) flux from an SPH-corrected GARNET result, **multiply** `result.flux` by `μ` of the cell's region and group: `φ = μΦ`. Reaction rates and power computed from the corrected cross sections and `Φ` are already reference-equivalent (`Σ̃Φ = Σφ^ref`); applying `μ` to the flux *and* using corrected cross sections would double count. Quantities that are not reaction rates with corrected coefficients, namely flux peaking, the `1/v` term and anything evaluated with uncorrected data against `Φ`, need the `μΦ` conversion (F7).
4. The normalization does not change any of these directions; on reflective problems it fixes the free constant per group, and it must be one constant per group (F2); with vacuum boundaries the consistent choice is no normalization with `k` fixed at the reference (F3, F5).
5. If a library ever supplies factors defined the other way round (`f = Φ/φ^ref = 1/μ`, "divide the cross sections by f"), convert with `μ = 1/f` before using GARNET's path; none of the surveyed codes does this.

## 6. Self-consistency test

Purpose: on the colorset or core used to generate the factors, the corrected coarse solve must reproduce the reference region reaction rates to the SPH tolerance, and its eigenvalue must be invariant to the normalization gauge. Failure of any item below indicates a bug independently of any external reference. The evidence scripts implement items 1–4 on the repository's own colorsets and on HP-MR.

Setup: reference solve (S_N, SP3 or Monte Carlo) on geometry `Ω`; `flux_weighted_homogenize` with region map `i(c)` and the physical cell volumes; `sph_correct` with tolerance `tol`; final coarse solve with `corrected_materials` giving `Φ_{i,g}` and `k_sph`.

1. **Reaction-rate reproduction.** For `x ∈ {absorption, production, out-scatter per group}` form `R^ref_{x,i,g} = Σ_{x,i,g} φ̄^ref_{i,g} V_i` and `R^sph_{x,i,g} = Σ̃_{x,i,g} Φ_{i,g} V_i`, each divided by its own total production `Σ_{i,g} R_{νf,i,g}`. Pass if `max_{x,i,g} |R^sph − R^ref| / max_{i,g} |R^ref_x| ≤ 10·tol`. (Dividing by total production removes the arbitrary eigenvector normalization; a per-group normalization constant must *not* be needed here.) **[measured]** 10⁻⁹ to 10⁻¹¹ on all converged runs, 10⁻³ on the non-converged "absolute" runs.
2. **Gauge invariance (reflective generation geometry).** Multiply the converged `μ_{i,g}` of one group by `c = 1.3`, re-solve: `|Δk| ≤ 1 pcm`; same for all factors at once. Catches the `D` convention (F1): **[measured]** 0.00 pcm with `μD`, +125 pcm with `D/μ` on the reflective assembly.
3. **Eigenvalue.** Reflective generation geometry: `|k_sph − k_ref| ≤ 1 pcm` (follows from item 1). Vacuum-bounded geometry with the fixed-k/no-normalization formulation: `|k_sph − k_ref| ≤ 1 pcm` and `|L_sph − L_ref| ≤ 10·tol` for the total boundary leakage `L = P/k − A`; with a normalized formulation report `k_sph − k_ref` as the leakage inconsistency rather than asserting on it.
4. **Identity limit.** Reference and coarse solve with the same operator, same mesh, one region per material: `max |μ − 1| ≤ 10·tol`, `k_sph = k_ref` (exists: `test_rz_sph_with_consistent_volumes_leaves_exact_regions_unchanged`). Add the flat-flux limit: a reference whose flux is spatially flat in every region (e.g. a homogeneous infinite medium) must give `μ = 1`.
5. **Physical flux.** `μ_{i,g} Φ_{i,g}` normalized to unit total production equals `φ̄^ref_{i,g}` likewise normalized, entry by entry, to `10·tol`; and the power edit from `with_materials(corrected)` equals `κΣ_f φ̄^ref V` to the same tolerance.
6. **Transfer check (assembly level).** Generate factors per assembly in a colorset with reflective boundaries (per-group flux–volume normalization), apply them to the same colorset on the coarse node mesh: items 1–3 must hold on the coarse mesh with the coarse region volumes. Then apply the same factors to a different environment (a shifted colorset or the core) and report, not assert, the `k` and assembly-power errors: that is the SPH transferability, not a bug.

Recommended first concrete instance for GARNET: C5G7 2-D (Tier 2 item 3): reference = GARNET fine S_N or SP3 on the pin-resolved colorset (the ADF study's `s = 4` mesh), regions = the four assemblies plus reflector, coarse = `N×N` nodes per assembly as in `examples/c5g7_colorset_adf.py`; items 1–5 with reflective outer boundaries, item 6 against the heterogeneous colorset. HP-MR (Tier 2 item 1) follows with the same script once a pin-resolved core or colorset S_N reference is available.

## 9. Follow-up, 2026-11-13: gauge check, rebuilt `sph_gauge.py`, and Kumar et al. 2026

### 9.1 How `D/μ` was chosen [code]

- 2026-07-10, commit `58246cc` (first factor solve): `_scale_material` "Multiply every cross section of `mat` by mu[g], and D by 1/mu[g]. Scaling the transport cross section 1/(3D) by mu is D -> D/mu." The test of that commit checks `k` on a reflective assembly, which both conventions pass (§9.2 B), so it could not distinguish them.
- 2026-07-28, commit `23f4b35`: the `D_SCALING` switch is introduced; `"inverse"` is kept because "measured on ndgpu's finite-volume leaky-colorset test 'inverse' is markedly better (SPH closes 4x of the homogenization error vs 2x)". That colorset has vacuum boundaries, where neither normalized formulation is consistent (§9.2 C).
- No gauge or uniqueness check of either convention exists in any version of the repository. §9.2 B is that check.

### 9.2 Rebuilt `sph_gauge.py` and re-evaluation

Script: [tools/assess_sph_gauge.py](../../tools/assess_sph_gauge.py). Outputs: [assess_sph_gauge_robin.out](sph_audit_evidence/assess_sph_gauge_robin.out) (the reference used by the lost script) and [assess_sph_gauge_marshak.out](sph_audit_evidence/assess_sph_gauge_marshak.out) (the current SP3 default). Geometry: the leaky colorset of `test_sph.py` (PWR fuel, poison stripe, 90 × 30 cm, vacuum in x) with the unequal region split the lost script used, x ∈ [0, 30), [30, 45), [45, 90) cm. That split was identified by search: it is the only one reproducing the documented `k_ref` and +885 pcm. Coarse node mesh for workflow (b): 7.5 × 15 cm. All numbers below are **[measured]**, Robin reference unless stated.

**Part A — reproduction.** The table of the implementation notes is reproduced to every printed digit:

| `D_SCALING` | sum-normalized `k` | volume-weighted `k` | spread | error vs reference (sum) |
|---|---|---|---|---|
| `inverse` | 1.1228525 | 1.1193008 | 355 pcm | +2363 pcm |
| `direct` | 1.1159805 | 1.1157147 | 27 pcm | +1676 pcm |

The notes say every run reported `converged=True`. SciPy's success flag is false in three of the four runs, yet all four satisfy the SPH condition to 10⁻¹¹ or better; the flag reflects the singular Jacobian left by the joint normalization (F2), not a wrong solution. Reading: the 355 pcm spread is F1 (with `D/μ` the normalization selects different physics); the 27 pcm spread with `μD` is the vacuum-boundary term; the +1676 and +2363 pcm errors are Labouré's normalization inconsistency on a vacuum geometry. Normalized SPH is not the right formulation for this geometry with either convention.

**Part B — gauge check on reflective generation geometries (question 3).** Same colorset with reflective boundaries, fine mesh (reference mesh) and coarse node mesh.

| Mesh | `D` | normalization | `k − k_ref` | rate error | group 0 ×1.3 | all ×1.3 |
|---|---|---|---|---|---|---|
| fine | `D/μ` | joint volume / per-group FV | 0.0 | ≤ 2·10⁻¹⁰ | +829 / +830 pcm | +957 / +949 pcm |
| fine | `μD` | joint sum / joint volume / per-group FV | 0.0 | ≤ 1.3·10⁻¹¹ | 0.00 | 0.00 |
| coarse | `D/μ` | joint volume / per-group FV | 0.0 | ≤ 1.5·10⁻¹¹ | +831 / +859 pcm | +902 / +979 pcm |
| coarse | `μD` | joint sum / joint volume / per-group FV | 0.0 | ≤ 2.7·10⁻¹⁰ | 0.00 | 0.00 |

1. On a reflective generation geometry every normalization reproduces `k` and the region rates under both conventions. The one exception is `D/μ` with the joint sum, which drifted to thermal factors of 10⁵¹ (fine mesh) and stopped with rate errors of 10⁻³: the joint normalization leaves one direction per group minus one free, and `D/μ` makes that direction non-flat.
2. With `μD`, scaling one group's factors changes `k` by 0.00 pcm, and the factor sets from the three normalizations differ only by one constant per group (fine mesh: joint-sum over per-group factors = 0.953 in every region for group 1, 5.28 for group 2). The normalization changes nothing on the generation geometry.
3. With `D/μ`, the same perturbation moves `k` by 830–980 pcm, and the three normalizations give factor sets that are not related by per-group constants. All of them reproduce the reference rates, so on a reflective geometry the `D/μ` factors are a family of physically different operators; the notes attributed this non-uniqueness to the normalization, but its cause is the convention.
4. The factors are large here (about 0.7 in the first two regions, 1.7 in the third) because the third region mixes the poison stripe with 30 cm of fuel; a plain Picard iteration converges to the same values, so they are not a solver artifact.

**Part C — vacuum generation geometry: which formulation works.**

| Mesh | `D` | formulation | `k − k_ref` | rate error | group 0 ×1.3 |
|---|---|---|---|---|---|
| fine | `D/μ` | joint sum (GARNET default) | +2363 pcm | 10⁻¹² | +2236 pcm |
| fine | `D/μ` | per-group FV | +1832 pcm | 8·10⁻⁴ | +2391 pcm |
| fine | `D/μ` | fixed `k_ref`, no normalization | 0.0 | 10⁻¹¹ | +2681 pcm |
| fine | `μD` | joint sum | +1676 pcm | 10⁻¹⁴ | +276 pcm |
| fine | `μD` | per-group FV | +1518 pcm | 6·10⁻⁴ | +238 pcm |
| fine | `μD` | fixed `k_ref`, no normalization | **no solution**: least-squares floor +873 pcm, factors → 0 | 1.5·10⁻³ | +22 pcm |
| coarse | `μD` | fixed `k_ref`, no normalization | **no solution**: floor +913 pcm | 1.7·10⁻³ | +10 pcm |

- A joint normalization preserves the rates but not the leakage, so `k` is wrong; a per-group normalization over-constrains a vacuum problem and preserves neither. Both are reflective-geometry tools (IGE-335, Labouré 2019).
- The fixed-`k`, no-normalization formulation (Griffin's, §9.3) has no solution here with `μD`. The reason [inferred, consistent with the measured drift]: with `D̃ = μD` a region-uniform factor leaves the flux shape inside the region unchanged; for a region on the vacuum face it only turns the Marshak condition `D∂Φ/∂n + (α/μ)Φ = 0` between reflective (μ → ∞) and zero-flux (μ → 0). The coarse leakage is therefore capped at the zero-flux limit, and this region split, which puts poison and fuel in one region at the vacuum face, needs more. `D/μ` reaches the reference only because dividing `D` changes the diffusion length inside the region, a hidden leakage factor. That is why it "looked better" in July, and its factors are not unique (gauge +2681 pcm). The principled leakage degree of freedom is a boundary discontinuity factor (Labouré 2019 SPH-DF), which GARNET's triangular operator already has (`bcf`).

**Part D — workflow (b) transfer: factors from the reflective colorset, applied to the vacuum colorset, coarse mesh.**

| Model in the vacuum colorset | `k − k_ref` | max region-power error |
|---|---|---|
| no SPH (reflective-environment cross sections) | +2799 pcm | 20.1 % |
| `D/μ`, joint sum / joint volume / per-group FV | +5086 / +4707 / +5328 pcm | 50 / 47 / 54 % |
| `μD`, joint sum / joint volume / per-group FV | +5166 / +5239 / +4625 pcm | 64 / 64 / 64 % |

Every SPH variant makes the transferred result worse than no SPH, and the transferred `k` depends on the normalization by about 615 pcm under both conventions. Under `μD` this is the per-group gauge, exact on the reflective generation geometry, broken by the vacuum boundary of the application geometry. The test geometry is deliberately extreme, but the outcome reproduces the documented failure of reflective-supercell SPH factors in a leaky core (INL/EXT-17-41516) and supports generating the factors in the full core, as Griffin does.

**Part E — generation time (F7).** Reflective colorset, fine heterogeneous diffusion as reference (`Λ = 2.0774·10⁻⁵ s`), per-group FV factors on the coarse mesh:

### 9.3 Kumar et al. 2026 and the development plan

S. Kumar, C. Lee, V. Labouré, Y. S. Jung, S. Terlizzi, Y. Wang, J. Ortensi, "Transient multiphysics simulations with pin power reconstruction in the Griffin reactor physics code", Ann. Nucl. Energy 230 (2026) 112111, doi:10.1016/j.anucene.2025.112111 (copy in `literature/`). Everything in this list is **[source]**, read in full.

1. **Workflow.** Serpent full core with vacuum outer boundary; cross sections homogenized over each hexagonal unit assembly; one SPH equivalence zone per fuel assembly; reference group fluxes per zone from Serpent detectors; factors solved by Griffin's PJFNK, referring to Labouré 2019 for the boundary treatment, i.e. fixed reference `k`, no normalization (§2.1.1, §2.3.1, §3.2). SPH is applied to the fuel only: "SPH factors are only calculated in the fuel regions" (§3.5.1).
2. **Convention.** Eq. (2): `Σ_{m,g} = μ_{m,g} Σ^ref`, `D_{m,g} = μ_{m,g} D^ref`, a further source for F1.
3. **Pin power.** Full-core form functions per pin and group, Eq. (4): `f_{p,g}` = reference pin `κΣ_f φ` tally ÷ (`κΣ̃_{f,m,g} Φ_{p,g}`), where `Φ_{p,g}` is the SPH-corrected coarse flux integrated over the pin footprint (12 sub-triangles per pin). Reconstruction, Eq. (5): `P_p = Σ_g f_{p,g} κΣ̃_{f,m,g} Φ_{p,g}`. Because the denominator comes from the coarse SPH solution, the form function absorbs the current error SPH leaves at the fuel–reflector interface ("the neutron currents at the fuel-reflector interface are not preserved using SPH equivalence", §2.1.2), and the generation state is reproduced exactly.
4. **State dependence.** Cross sections and factors are tabulated in fuel, moderator/monolith and reflector/drum temperature (150 K steps) and drum angle, with linear interpolation. Form functions barely depend on temperature: one 600 K set gives pin-power RMS 0.4–0.5 %, maximum 1.9 %, over the temperature grid (Table 2). They depend strongly on drum angle: linear interpolation on a 60° grid gives large pin errors between 0° and 60°, and the transient used a 5° grid (§3.3.2, §3.5.1–3.5.2).
5. **Drums.** A homogenized drum with fuel-only SPH errs by up to 261 pcm between tabulated angles; an explicitly meshed drum and reflector errs by 199–253 pcm and is the recommended practice (§3.5.1, Fig. 19).
6. **Transient.** Against a heterogeneous DFEM-S_N transient, pin-power RMS ≤ 3.5 % and maximum 5.2 %, or ≤ 0.6 % and 2.0 % at matched total power (§3.5.3). Velocities and kinetics parameters are not discussed; Griffin uses the uncorrected `1/v` (Takasugi et al. 2023, Eq. 8).
7. **Authors' future work.** 3-D; higher-order interpolation of form functions in drum angle; discontinuity factors or hybrid SPH-DF to reduce the drum-angle sensitivity (§4).

Comparison with GARNET [code for the GARNET column]:

| Step | Griffin (Kumar 2026) | GARNET today |
|---|---|---|
| Reference | Serpent full core, vacuum | any GARNET result on the same mesh; examples use SP3/SDPN/tri-S_N, material-wise |
| Equivalence zones | one per fuel hex, fuel only | one per material; no restriction option (F12) |
| Factor solve | Newton, fixed `k_ref`, no normalization, `μD` | joint-normalized eigen fixed point, `D/μ` (F1–F3) |
| Coarse mesh | 6 triangles per hex; reflector and drums meshed explicitly | 6r² triangles per hex; drum arc volume-mixed in its own cells, Be hexes separate, so already "explicit" |
| Pin power | full-core per-group `f_{p,g}`, pin-footprint flux integral, consistent with the coarse SPH solve | single-assembly infinite-lattice form function, group-collapsed, times the coarse power density at the pin centre ([pin_power.py:1–26](../../garnet/pin_power.py#L1-L26)) |
| State dependence | tables of cross sections, `μ`, `f`; `f` at ≤ 5° in drum angle | feedback hooks scale the corrected cross sections; `μ` fixed (F8) |
| Kinetics | uncorrected `1/v` | uncorrected `1/v` (F7) |

What changes in the plan, in order:

1. **Unchanged:** fix the convention (F1) and the normalization (F2) first; rewrite the leaky-colorset test (F10).
2. **Generation environment and formulation.** The primary path becomes a full-core reference with vacuum boundary, one zone per fuel assembly, SPH restricted to the fuel, fixed reference `k`, no normalization, solved by Newton (F3, F12, F14). Reflective colorsets with per-group flux–volume normalization remain for verification only; part D shows that reflective-environment factors do not transfer and that their per-group gauge moves the core `k` by hundreds of pcm.
3. **Existence and fallback.** Part C shows the fixed-`k` problem with `μD` can have no solution when a zone at a vacuum face carries an intra-region shape error. Griffin avoids this by not correcting reflector and drum regions and by meshing them explicitly, which GARNET's HP-MR raster already does. Keep the boundary-coefficient (SPH-DF) variant as the fallback, and have the solver report its least-squares floor instead of a converged flag (F9).
4. **New: full-core, per-group form functions** (Eq. 4–5), computed in the same coarse solve as the factors, with the coarse flux integrated over each pin footprint on the triangular raster. The reference must tally pin-wise group `κΣ_f` rates as well as zone fluxes. Keep the current infinite-lattice reconstruction for comparison and for states without a full-core reference.
5. **New: state tables** of cross sections, factors and form functions in fuel, moderator and reflector temperature and drum angle, with linear interpolation and ≤ 5° drum spacing for form functions (or higher-order interpolation). Temperature feedback then goes through the table instead of scaling corrected cross sections (F8). Because the drum is already explicit in GARNET, the 261 pcm intermediate-angle error of Griffin's homogenized-drum variant should not apply; verify it.
6. **Transients:** per-zone `v/μ` (F7), which goes beyond Griffin's practice and is justified by the transform and part E; then compare a drum transient against a heterogeneous tri-S_N transient, as Kumar §3.5 does.
7. **Tests:** §6 gains a construction check (reconstructed pin powers equal the reference pin rates at the generation state) and off-state checks (temperature grid, drum angles between tabulation points), the quantities of Kumar Table 2 and §3.5.1.
8. **Validation targets:** HP-MR with GARNET's own pin-resolved tri-S_N full-core references; a code-to-code comparison with Kumar's SIMBA numbers is approximate only, because the SIMBA variants differ between papers (INL/RPT-23-74793 Table 2: 120° arcs, 15.0 cm drum, 32 cm assembly; Kumar Table 1: 90°, 14.8 cm, 32.353 cm) and the base specification (Terlizzi & Labouré, Ann. Nucl. Energy 186 (2023) 109735) was not opened.
